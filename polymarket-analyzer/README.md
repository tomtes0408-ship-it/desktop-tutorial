# Polymarket User Portfolio Analyzer

## מנתח פורטפוליו של משתמשי Polymarket

כלי לניתוח מעמיק של פורטפוליו והשקעות משתמשים ב-Polymarket.

### תכונות

- **חילוץ נתונים** - מושך את כל הפוזיציות של משתמש מ-Polymarket API
- **ניתוח אסטרטגיה** - מזהה דפוסי השקעה, העדפות סיכון, וסוג אסטרטגיה
- **ניתוח רווח/הפסד** - מחשב ביצועים כוללים, אחוז הצלחה, ורווחים/הפסדים
- **תרשימים ויזואליים** - יוצר גרפים להמחשת הנתונים
- **ייצוא נתונים** - מייצא ל-CSV ו-JSON

### התקנה

```bash
cd polymarket-analyzer
pip install -r requirements.txt
```

### שימוש

```bash
# ניתוח משתמש ספציפי
python polymarket_analyzer.py anoin123

# או עם @
python polymarket_analyzer.py @anoin123
```

### פלט

הכלי מייצר:
- `analysis_report_USERNAME.txt` - דוח ניתוח מלא בעברית
- `positions_USERNAME.csv` - טבלת פוזיציות
- `positions_USERNAME.json` - נתונים בפורמט JSON
- `portfolio_analysis_USERNAME.png` - תרשימי ניתוח
- `cumulative_pnl_USERNAME.png` - גרף רווח מצטבר

### מידע על API

הכלי משתמש ב-APIs הציבוריים של Polymarket:
- Gamma API: `https://gamma-api.polymarket.com`
- Data API: `https://data-api.polymarket.com`
