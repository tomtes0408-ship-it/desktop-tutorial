## הוראות הפעלה

### שיטה 1: Python API (מהירה יותר)
```bash
cd polymarket-analyzer
pip install -r requirements.txt
python polymarket_analyzer.py anoin123
```

### שיטה 2: Browser Scraper (מקיפה יותר)
```bash
cd polymarket-analyzer
npm install
node browser_scraper.js anoin123
```

## תרשימים שנוצרים

### 1. התפלגות רווח/הפסד
גרף עמודות המציג את הרווח/הפסד של כל פוזיציה - ירוק לרווח, אדום להפסד.

### 2. התפלגות סוגי פוזיציות
תרשים עוגה המראה את היחס בין פוזיציות Yes ל-No.

### 3. התפלגות מחירי כניסה
היסטוגרמה של מחירי הקנייה - מזהה את העדפות המחיר של הסוחר.

### 4. רווח מצטבר
גרף קווי המראה את התפתחות הרווח/הפסד לאורך זמן.

---

## פרמטרים לניתוח אסטרטגיה

| פרמטר | מה הוא מודד |
|-------|-------------|
| Win Rate | אחוז הפוזיציות הרווחיות |
| Avg Entry Price | מחיר כניסה ממוצע - מראה העדפת סיכון |
| Position Size | גודל פוזיציה ממוצע - מראה רמת מחויבות |
| Yes/No Ratio | יחס בין סוגי הימורים |
| Volatility | סטיית תקן - מראה עקביות |

---

## סוגי אסטרטגיות מזוהות

1. **Long-shot Strategy** (מחיר כניסה < 30%)
   - הימורים על אירועים בסיכוי נמוך
   - פוטנציאל רווח גבוה, סיכון גבוה

2. **Safe Bet Strategy** (מחיר כניסה > 70%)
   - הימורים על אירועים בסיכוי גבוה
   - רווח נמוך אך עקבי

3. **Balanced Strategy** (מחיר כניסה 30-70%)
   - שילוב של שתי הגישות
   - גיוון סיכונים
