# 🎓 עוזר אישי לסטודנט - Student Assistant

מערכת ניהול משימות, לוח זמנים ותזכורות מקיפה המיועדת לסטודנטים באוניברסיטה.
כל הממשק וההודעות בעברית.

## ✨ תכונות עיקריות

### 📝 ניהול משימות מלא
- יצירה, עריכה ומחיקה של משימות
- עדיפויות (דחוף מאוד עד לא דחוף)
- קטגוריות (שיעורי בית, מבחנים, פרויקטים, ועוד)
- תתי-משימות - פירוק משימות גדולות לחלקים קטנים
- מעקב סטטוס (ממתין, בביצוע, הושלם)
- חיפוש וסינון מתקדם

### ⏰ מערכת תזכורות
- תזכורות מותאמות אישית
- התראות אוטומטיות על דדליינים
- תזכורות חוזרות (יומי, שבועי, חודשי)
- תזכורות מהירות ("תזכיר לי בעוד X דקות")

### 📅 תכנון לימודים
- יצירת סשני לימוד
- תכנון אוטומטי של לוח זמנים
- מעקב פרודוקטיביות
- חישוב עומס עבודה
- טיפים ללימוד יעיל

### 📚 ניהול קורסים והגשות
- רישום קורסים עם פרטי מרצה ונקודות זכות
- מעקב הגשות עם ציונים
- קישור משימות לקורסים

### 📊 סטטיסטיקות ודוחות
- תדריך יומי
- סיכום שבועי
- מגמת פרודוקטיביות
- יומן פעילות

### 💡 עוזר פרואקטיבי
- אזהרות על דדליינים מתקרבים
- הצעות לפירוק משימות גדולות
- המלצות לתכנון זמן
- זיהוי צווארי בקבוק

## 🚀 התקנה

### דרישות מקדימות
- Python 3.8 ומעלה

### התקנה
```bash
# שכפול הפרויקט
git clone <repository-url>
cd student-assistant

# התקנת תלויות (אופציונלי - לחוויה משופרת)
pip install -r requirements.txt
```

## 📖 שימוש

### הפעלה רגילה (ממשק אינטראקטיבי)
```bash
python run.py
```

### פקודות מהירות
```bash
# תדריך יומי מהיר
python run.py --quick
python run.py -q

# הוספת משימה מהירה
python run.py --add-task
python run.py -a

# הצגת רשימת משימות
python run.py --list
python run.py -l

# הצגת דדליינים קרובים
python run.py --deadlines
python run.py -d

# סטטיסטיקות
python run.py --stats
python run.py -s
```

## 📁 מבנה הפרויקט

```
student_assistant/
├── __init__.py          # אתחול החבילה
├── config.py            # הגדרות ותצורה
├── database.py          # שכבת מסד נתונים SQLite
├── models.py            # מודלים (Task, Reminder, etc.)
├── task_manager.py      # ניהול משימות
├── scheduler.py         # תזכורות ותזמון
├── planner.py           # תכנון לימודים
├── proactive.py         # עוזר פרואקטיבי
├── ui.py                # ממשק משתמש
└── main.py              # נקודת כניסה

data/
└── student_assistant.db # מסד הנתונים (נוצר אוטומטית)

run.py                   # סקריפט הפעלה
requirements.txt         # תלויות
```

## 💡 טיפים לשימוש יעיל

1. **התחל כל יום** בצפייה בתדריך היומי (`--quick`)
2. **פרק משימות גדולות** לתתי-משימות קטנות
3. **הגדר תזכורות דדליין** למשימות חשובות
4. **עקוב אחר הפרודוקטיביות** דרך סשני הלימוד
5. **סקור את הסטטיסטיקות** השבועיות לשיפור מתמיד
